# UniFi 风格的 NAS 触控界面

> 初次重构的历史记录。当前界面以 [技能 1.1 全界面迭代](ui-unifi-v11-2026-10-12.md) 为准；以下底部导航和卡片排布已被后续版本替换。

## 设计基线

采用 `unifi-ui-design` 技能中 2026-10-12 记录的 UniFi Network 10.6.106 深色界面观察：中性工作区、独立应用栏、蓝色交互强调、全局导航与工作区分层。参考观察视口为 2205×1175 CSS px、桌面鼠标，发布通道与浏览器缩放未核实，原界面带翻译层。它是指定版本的观察记录，不是跨版本的官方设计规范，也不是本轮重新登录控制台取证。

本项目使用 LVGL/C、Inter + Noto Sans SC，目标为 1024×600 触摸屏。NAS 实体与指标保持真实领域语义，不增加虚构拓扑或端口。圆角、触控尺寸、图表序列色、健康色和导航折叠规则均是项目适配。

## 实现

- `uk_theme.c` 新增默认 `unifi` 主题：画布 `#131416`、应用栏 `#282B2F`、主要文字 `#F9FAFA` / `#DEE0E3`、交互蓝 `#4797FF` 来自记录的视觉角色；其余颜色为满足可读性的项目选择。
- 将原来的蜜桃/薄荷装饰角色改为资源主卡、资源辅卡、摘要表面和摘要前景的语义令牌。旧配色仍可显式选择；深色摘要在夜间模式不再被当成浅色卡反转文本。
- 视口有足够空间容纳导航及首选比较列时使用左侧导航，否则保留底部触控导航。布局由 LVGL flex 计算，设备数量与名称不参与断点。导航数量仍来自现有页面定义。摘要卡在宽度不足时改为纵向排列；断点使用可用容器宽度与配置的清单首选宽度。
- 总览保持健康带与明细入口，CPU / 内存的读数、真实历史为主，运行时长退为辅助行；不改变采集周期、缺失值、历史断流或旧快照语义。连接失败的具体原因在顶部状态带换行显示。
- 列表统一为中性表面和细分隔线；名称换行、动态数量、滚动与空态继续使用共享控件。

## 配置与复现

新配置默认 `CONFIG_FNOS_PALETTE="unifi"`。已有 `sdkconfig` 的显式旧值不会被 defaults 强制覆盖，需要同步选择 `unifi` 并重新构建。主机预览可用 `KK_PALETTE=unifi`，颜色必须在 UI 创建前选定。

```bash
bash tools/gen_fonts.sh
./idf.sh build
python3 tools/stack_check.py
bash tools/preview/run.sh out-unifi
```

字库使用既有生成脚本，不手改生成物。导航宽度、触控尺寸、比较列数和图表最小高度集中在 `uk_theme.h` / `uk.h`，不依赖某台 NAS 的硬件数量。
