# 首页稳定刷新优化

沿用 [分段测量](perf-parts-2026-10-15.md) 与 [绘制测量](perf-draw-2026-10-15.md) 的结论，先消除已经确认的重复失效，不改历史数据、设备数量、刷新节拍或动效。

## 实现

`overview_layout` 继续按实际内容计算所有最小高度，仅在局部值不同或尚未设置时写入。`overview_refresh` 对颜色与透明度采用同样的局部值检查，CPU/MEM 曲线身份色相同时不再调用会强制刷新图表的 setter。比较精确 selector 的局部值，而不是计算后的继承值，因此首次显式覆盖和后续状态/主题变化仍然生效。

新增 `CONFIG_FNOS_UI_PERF_DRAW`，依赖台架开关，默认关闭；仅在需要归因时开启高频软件绘制探针。四项低频显示管线探针保留。性能对照不启用高频探针。

## 可复验的结果

- 原代码在四次相同数据刷新中产生四次 CPU 卡片 `STYLE_CHANGED`，新增断言失败；优化后为零，断言通过。
- 完整主机预览通过，覆盖清单增减、长名称、状态与色阈值、分配失败重试及动效。与此前低频版本输出比较，114 张同名 PNG 字节完全一致。
- ESP-IDF 5.5.3 构建、GCC analyzer、计时解析回归及最终 ELF 静态栈检查通过；两名只读审查者未发现本轮功能/规格缺陷。

## 实机对照

设备已运行候选版本 `a2bed5e6d`，与当前构建 ELF 前缀一致；应用哈希校验通过。基线为已温机的低频分段版本 `04c458222`，候选首次重启后的测试另存，以下采用趋势历史填满后的第二轮结果。

| idle:0:10 | 17.6 → 25.7 | 27.720 → 5.722 | 45.481 → 33.431 |
| swipe:0:0:3 | 13.6 → 16.3 | 4.494 → 3.675 | 47.375 → 49.235 |
| idle:2:10 | 25.3 → 28.1 | 24.324 → 24.694 | 29.178 → 26.888 |

| idle:0:10 | 16.4 → 25.5 | 38.851 → 5.587 | 44.703 → 33.268 |

首页稳定刷新中位耗时明显下降；拖动与点击的计时区间平均耗时并非全面改善。FPS 的窗口含义也与计时帧区间不同，不能混算。设备使用实时遥测，输入未冻结；同组台架结果只能说明本次运行表现，不能将全部差值归因于本次修改。LVGL 渲染 FPS 不等于面板显示 FPS。重启后首次首页 idle 的 48.1 FPS 不作为稳定态收益。

两轮候选五组用例均完整返回，手势 misses 为零，日志未见崩溃标记；心跳固件身份一致，采集失败计数未增加。新鲜相机图像确认首页布局正常显示，单张图不作为动态流畅度验收。保留候选固件运行，上一低频版本镜像可回滚。

本轮备份、固件、原始串口日志与相机图像保留在开发目录的本地排除路径，未提交或推送。
