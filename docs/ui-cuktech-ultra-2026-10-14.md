# ULTRA 参考版：黑底、白字与蓝青强调

本轮依据用户提供的酷态科 ULTRA 产品图，并叠加两次明确修正：黄色改为蓝色，红色去掉粉感。使用 `cuktech-screen-ui`，在现有 `cuktech-console` 候选主题内统一六页、详情、诊断、配网、配对与夜间界面；用户确认本版后要求发布与烧录；默认配置、预览初始主题和未知主题回退统一为 `cuktech-console`。

## 视觉与数据合同

目标是 ESP32-P4 7B 的 1024×600 横屏 LCD/RGB565。黑底与白色主读数占主导，小面积标签、曲线与仪表承担颜色。用户图片提供视觉方向，以下色值为项目适配值，并非官方色值或实测面板取色。参考图中的商品外壳、营销背景和竖屏比例不进入本项目。

| 角色 | 色值 / 规则 |
| --- | --- |
| 画布 / 卡片 / 浮层 | `#000000` / `#101010` / `#181818` |
| 主读数 / 正文 / 辅助标签 | `#F8F8F8` / `#E0E0E0` / `#B8B8B8` |
| 选中、操作、提醒 | 蓝色 `#75BFFF`，替代黄色 |
| CPU 历史 / 上行身份 | 橙色 `#FFA23A` |
| 内存历史 / 下行身份 | 冰青 `#8ED7E5` |
| 正常健康 / 严重异常 | 绿色 `#8ED49C` / 朱红 `#FF5A45` |
| 占用率低 / 提醒 / 接近上限 | 冰青 / 蓝 / 朱红，使用现有配置阈值 80% / 90% |

占用率只给当前圆弧、容量进度条着色；历史曲线始终保持指标身份色，不因当前占用升高而把整段旧历史染红。首页和存储卷的百分比、网络主速率以及首页容器数量保持主文本色；失效读数继续降灰。告警等级、容器运行/停止等事实文字继续显示，颜色不是唯一依据。蓝色同时出现在操作与提醒中时，由控件形态和明确文案区分，不能将其单独理解为错误。

当前实现使用既有共享主题与刷新入口；读数/曲线规则适用于所有预置，ULTRA 的具体底色和强调色只属于 `cuktech-console`。没有新增主题、布局体系、依赖或动效算法。主值和单位、实体顺序、动态清单、长名称和滚动可达保持；网速曲线仅在网络页。CPU/内存/温度历史仍是各自量纲。

数据继续来自已有快照和采样历史；实时、旧值、离线、无数据、真实零值沿用既有判断。保留现有 4 bpp 字库、原生字号、首帧策略、TRIPLE_PARTIAL 缓冲、阻尼与资源不足提示。本轮无需生成新字形。

主机渲染、构建和静态检查不等于实屏色彩、触摸、刷新或长期稳定性验收。后续发布、烧录与运行结果见[本轮归档](ui-ultra-release-2026-10-14.md)；不拍照、不部署 NAS、不重打 FPK。
