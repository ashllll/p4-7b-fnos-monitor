# UI 整改验证（2026-10-07）

根据 `ui-ux-audit-2026-10-07.md` 的九项问题，使用 ui-skills 路由的 interface-design 在真实 C/LVGL ui_kit 上整改。开发工程为 `/Users/llll/code/esp/p4-7b-fnos-monitor`；保留已有未提交迁移，不提交、推送或发布固件。本轮未烧录，实机验收仍待进行。

## 实现

| 审核问题 | 当前行为 |
| --- | --- |
| 诊断同页导航留下空白 | 所有覆盖层开关同步正文；点击当前系统导航也恢复正文，重复点击保持页面选择。 |
| 底栏丢失严重事件 | 按 crit / warn / info 选择首要事件，同级保持原顺序，并显示事件总数。 |
| 离线状态误导 | 容器显示上次状态，事件标记上次采集，底栏优先说明离线；历史事件不触发严重呼吸动画，温度条降级。 |
| 风险语义与阈值混杂 | 使用 `CONFIG_FNOS_UI_*` 统一视觉参考；默认使用率 80/90%、温度 75/80°C，可在 menuconfig 修改。温度页明确标注参考区间，健康结论依据采集事件。 |
| 系统窄屏越界 | 外层卡根据内容宽度重排，800×480 为两列加整行事件区；列表和诊断正文可以纵向滚动。顶栏按文字与剩余宽度布局。 |
| 同型号设备身份丢失 | 消歧标识放在副行开头；容器名称和状态分行，长状态不挤掉身份。 |
| 失败恢复动作不匹配 | 本地保存/资源错误显示对应恢复建议并保留原始原因；Wi-Fi 失败主操作为修改密码，成功后才显示完成。 |
| 总览趋势空缺 | 趋势填充余下高度，健康结论提高层级，容量数字收至 32px。 |
| 温度空缺和跳切 | 每次重测前释放旧最小高度；默认设备摘要，点按展开/收起全部通道。普通采样不竞争展开资格；设备新增或消失时按稳定 ID 保留选择。 |

通道详情按需分配，可覆盖协议上限 48 路，不再截为每设备 8 路。设备块的字号、单位基线和阅读顺序保持一致；列内容预留滚动条条带及间距。参考颜色不能作为设备硬件安全限值；协议目前没有逐设备限温元数据，因此未按型号猜测限温。

## 验证

- Debug 构建真实 LVGL，保留断言；1024×600、800×480、1280×800 完整预览各 67 张。
- 原有字库、标签、父子边界、点击重叠、文本重叠和滚动检查继续执行。可点击范围审计按祖先裁剪，避免把滚动区内长设备块错误判作覆盖顶栏；重叠容差未放宽。
- 新回归涵盖最高严重度、离线容器、诊断同页退出和连续点击、CPU 两轮展开收起高度、40 拍温度波动保持位置、48 路逐项存在及末路滚入视口、展开态持续刷新、设备插入/删除保留展开选择、Wi-Fi 失败修改密码并重新连接、NVS 失败恢复提示、合法 32 字节 SSID 顶栏省略及边界、31/32 字节名称连接中文案完整性（状态优先于名称）、长主机名边界。
- 主模型检查实际 PNG，包含五页、离线、失败、窄屏配对、温度展开/收起；预览不代替物理屏幕、GT911 或实际网络时序验收。
- ESP-IDF 5.5.3 / ESP32-P4 rev3.x 构建及 `tools/stack_check.py` 通过。栈检查是静态下界，不能证明中断、动态回调和实机稳态内存。
- 采集错误标签契约 `tools/reason_check.py` 通过。

构建使用项目 `idf.sh`；技能通用 IDF helper 选到了缺少 esp_idf_monitor 的 Python，已使用工程现有且验证成功的环境包装完成构建。主机仅从生成配置读取公开 UI 项，不导入网络凭据。

DSH Desktop 已完成原审核基线的有界只读复核。最终修复差异的 DSH 复核因其他任务持有共享桌面锁而停止，未绕过锁；最终代码由 Codex 和独立 Codex 代理复核，不宣称 DSH 已通过最终差异。

## 重现

先执行 `./idf.sh reconfigure`（新增 Kconfig 时），再 `./idf.sh build`。改文案时运行 `bash tools/gen_fonts.sh`。

```bash
DEVELOPER_DIR=/Library/Developer/CommandLineTools cmake -S tools/preview -B /tmp/fnos-ui-preview -DCMAKE_BUILD_TYPE=Debug
DEVELOPER_DIR=/Library/Developer/CommandLineTools cmake --build /tmp/fnos-ui-preview --target preview -j8
/tmp/fnos-ui-preview/preview /tmp/fnos-ui-render
PREVIEW_SIZE=800x480 /tmp/fnos-ui-preview/preview /tmp/fnos-ui-render-800
PREVIEW_SIZE=1280x800 /tmp/fnos-ui-preview/preview /tmp/fnos-ui-render-1280
python3 tools/preview/ppm2png.py /tmp/fnos-ui-render
bash -c 'source /Users/llll/code/esp/use-esp-idf-5.5.3.sh; python3 tools/stack_check.py'
```
