# ULTRA UI 优化与发布归档 · 2026-10-14

## 最终交付

本轮从暖中性、UniFi 深色、黄绿候选，收敛到用户提供的 ULTRA 产品参考。最终选择黑底、白色主读数、蓝色交互与提醒、冰青/少量橙色指标身份、朱红严重异常；黄色及偏粉红不再用于默认主题。`cuktech-console` 成为固件、预览与未知主题回退的默认值。

覆盖六页、详情、诊断、配网、键盘、配对、夜间和异常状态。首页保持多功能密度，网速曲线仅在网络页，设备数量、长名称、滚动可达和已有临界阻尼保持。主数字回归白色，负载只给圆弧/进度条着色，历史不被当前负载重染。分数阈值与非法值处理集中在共享函数。

README 替换为最新 21 张匿名 LVGL 原图，补充占用率规则和升级主题设置；两张流程图保持既有结构并同步蓝青配色。NAS 管理页仅同步 CSS，不修改接口、权限或业务脚本。本次不重新打包或部署 FPK，仓库 1.2.7 包内仍为此前皮肤。

## Skills 流程与复盘

范围和目录检查 → CodeGraph/当前源码阅读 → `cuktech-screen-ui` 与共享模块实现 → 原生渲染与构建 → `code-review` 两轴审查 → `retro`/`writing-for-agents` 归档 → 发布检查 → `build-idf`/`flash-idf`/`serial-monitor` 实机验证。流程图沿用 `diagram-design`。

- 设计偏差来自把品牌色扩大到整个仪表状态，并把最新占用率用于整条历史。改为先定义黑白与局部强调的比例，再检查正常、提醒、上限三档实际渲染；不靠品牌名推断用户偏好。
- 默认配置、运行时初值、未知值回退与预览入口必须一起核对，避免只更新候选截图而烧录旧主题。本轮已对齐。
- 同名主题迭代后，历史图册不能继续声称可由当前命令复现；用历史提示、图像与源码指纹保存证据。
- 既有原生审计继续检查字形、越界、触控重叠、格式残留、动态清单及资源不足；新增的占用状态样图与检查复用该入口。未引入独立测试框架或修改全局技能。

实机 ELF 的静态栈下界：主任务 4752/16384 B、LVGL（含显式回调估计）4720/12288 B、轮询 4576/6144 B；其余受检入口也在预算内。这不能覆盖所有动态函数指针、中断嵌套与最坏运行路径。

烧录沿用已有串口画像。自带烧录 helper 曾受固定 120 秒超时限制，本轮使用技能允许的官方工具回退。串口 helper 退出 1，原因是把每行的 `fail=0` / `"fail":0` 计为 FAIL；复核 13 行均为 ESP-IDF 信息级输出，失败计数为 0，并非忽略真实故障。

私有构建快照、固件、原始日志和验证报告只保存在开发目录的 `.local-artifacts/ultra-release-2026-10-14/`；发布仓库仅保存源码、模板和脱敏结果。开发目录旧副本未被批量同步，后续应以本次发布源码与私有快照作为这一版的基线。

按用户要求，本轮未拍摄物理屏幕。短时串口结果不代表完整触控、肉眼动效、长期稳定性或所有实机页面验收；这些边界继续保留。当前提交未改动动效控制器，也未重新宣称完成独立动效全量验收。
