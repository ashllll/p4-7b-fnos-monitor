# 暖中性仪表配色

> 历史归档：本页记录当时的候选、命令和验证，不代表当前默认版；当前源码无法保证复现旧图。最终方案与发布情况见 [ULTRA 设计](ui-cuktech-ultra-2026-10-14.md)及[本轮归档](ui-ultra-release-2026-10-14.md)。

用户要求全面迭代配色并去掉蓝紫色。按 `cuktech-screen-ui` 保留仪表、数字优先及状态分层的语法，更新色彩合同；这是共享主题与组件默认色调整，没有改变 ADR-0001 的原生 LVGL 架构。

## 色彩合同

| 角色 | 默认值 | 用途 |
| --- | --- | --- |
| 背景／卡片 | `#080807`／`#151411` | 炭黑与暖灰，收敛大面积彩色 |
| 主字／次字 | `#F1EDE4`／`#B9B0A2` | 象牙白主读数、暖灰辅助文字 |
| 交互焦点 | `#C7AD7D` | 香槟金导航、选中与主操作 |
| CPU／下行 | `#E8E2D6` | 象牙白仪表与趋势 |
| 内存／上行 | `#BCA580`／`#C7AD7D` | 稳定的香槟色系身份 |
| 温度 | `#D3A286` | 暖铜读数与趋势 |
| 正常／提醒／异常 | `#A8BF8D`／`#E2B66E`／`#E88B78` | 低饱和绿、琥珀、朱红；继续配合状态文字 |

仅覆盖当前 1024×600 横屏。六页、详情、诊断、Wi-Fi、键盘、配对、失败及夜间状态复用同一套令牌。既有六个预置名称保持配置兼容，全部更新为暖中性变体；字段名 `blue` 沿用 ABI 名称，实际表示交互焦点。趋势组件初始序列色改从当前主题读取，避免显式设色前短暂露出旧蓝色。

飞牛管理页 CSS 也采用同一体系，信息提示回归中性色，主按钮使用深字配香槟底，移除彩色光晕；没有修改页面请求、权限或配对逻辑。README 两张文档图和 15 张匿名 LVGL 产品渲染图同步更新；文档图由 `diagram-design` 重新导出。

## 验证与边界

- 默认主机流程包含 105 张状态图及 3 张刷新回归图，通过字形、格式残留、边界、触控重叠与对比度审计；empty／compact／mixed／dense 清单、快照及受控分配失败恢复检查通过。
- 其他五个预置各渲染 105 张状态图并通过同一审计。`palette_check.py` 检查全部可选主题令牌及实际 PPM 像素；容许 RGB565 独立通道量化的 8 级误差，拒绝蓝／紫通道回归。默认预览入口已接入该检查。
- ESP-IDF 5.5.3／ESP32-P4 rev3.x 构建通过；新 ELF 静态栈下界检查通过。只改主题与趋势初始化色，不改变采集频率、阻尼参数、页面结构、字库或缓冲。没有重新生成字体。
- 实际目视检查六个主页面和主要输入、详情、诊断与夜间画面。此为匿名主机渲染；物理屏幕色偏、低亮度、视角及操作手感仍需实屏验收。
- 本轮没有烧录、NAS 部署、FPK 重打包、提交或推送；仓库现有 FPK 安装包仍对应此前的管理页皮肤。按用户既有要求不拍摄物理屏幕。

复现：`bash tools/preview/run.sh out-warm-20261014`；单独检查 `python3 tools/preview/palette_check.py <PPM目录>`。公开图片的源码指纹与逐文件校验值见 [manifest](images/ui-2026-10-14/manifest.json)。
