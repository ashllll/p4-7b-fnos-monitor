## 1. 总评

这一版的方向是对的，而且比上一轮明显更像一台仪表：黑底、细线、蓝青焦点、数字和卡片层级统一；底栏 44px 触控、112+3 帧对比度最低 6.07:1、切页临界阻尼、数字/仪表节拍、过滤跨页保留、配对码保留、详情冻结等都已实测 PASS。**不要换皮。**

问题集中在三处，不是配色：

1. **首屏布局承诺没有兜住。** 设计文档写「九宫格等宽等高、页面无滚动且全部完整可见」（`docs/ui-cuktech-2026-10-14.md:26`、`docs/ui-design-language-2026-10-15.md:35`）。实测 live 总览九宫格三行各 165px，页视口只有 476px，内容底 578px，**第三行 43px 在首屏外**；存储页内容底 767px（+232），**「磁盘活动」整卡在首屏外**，卷/阵列卡底 76px 被裁。系统/温度/告警在数据多时同样溢出（+198/+512、+213、+162）。页根虽可滚，但滚动条被显式关闭，没有边缘渐隐/「更多」提示。
2. **状态语义仍会读错。** 首采前温度卡写「离线 · 显示上次快照」并给「离线，显示最后一次采集快照」，同屏顶栏却是「等待数据/等待采集端」，值恒为 `--`；离线原因「连不上 NAS：…」只挂在最热温度卡脚注上。告警页四条正文直接打印上游英文。容器详情把「上次运行中」打印两遍。
3. **交互把覆盖层当页面切换。** `fnos_ui_set_page()` 在判「是否当前页」之前关闭配对/配网，配网关闭第一行清空已输入口令；点当前页、任意底栏、顶栏都会触发。配对码不丢，但 Wi-Fi 口令会无提示丢失。

**为什么 `tools/preview/run.sh` 全 PASS 仍有 P0？** 因为页级溢出不在审计覆盖内：`audit_bounds` 对「可滚父」跳过直接子对象；九宫格等高断言只在 synthetic zero 夹具上跑；`06-*-scroll` 只滚卡内列表；`PREVIEW_PAGE_CARDS` 取错 screen 子对象；过渡帧 barmap 早于 settle；`audit_list_floors` 只比清单自身高度；`PREVIEW_MOTION_SCROLL` 在页 0 直接 exit 134。详见 §4。**这份报告的主结论是：现有绿灯不能证明首屏完整。**
