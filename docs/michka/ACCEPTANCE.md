# 验收计划与证据模板

初稿：2026-10-22；发布复核：2026-10-25。状态：完整迁移验收未通过，本目录不登记未经复核的分段试验为 AT 通过。
需求关联：[PRD](PRD.md)。本文件是性能门槛和测试方法的唯一维护位置。

## 1. 门槛与统计口径

| 指标 | 门槛 | 统计口径 |
| --- | --- | --- |
| 动态实际呈现帧率 | 平均≥25 fps，目标30 fps | 同一持续动画／拖动场景≥5分钟；只数不同且实际呈现的有效帧 |
| 动态帧间隔 | P95≤80ms | 记录所有动态帧间隔；>500ms停顿单列原因与数量 |
| 触摸到可见反馈 | 中位数≤100ms且P95≤150ms | 每类主要操作至少100次，报告分布和样本数 |
| 恢复时间 | 服务健康可达后≤10秒 | 区分远端启动时间与客户端恢复时间；10次注入逐次记录 |
| PoC稳定性 | 连续2小时无崩溃／重启／持续资源增长 | 固定场景循环，记录堆、队列、帧率及主机资源 |
| 长期稳定性 | 24小时通过后再72小时 | 配置固定，覆盖昼夜背光／正常操作／网络扰动 |

静止画面不产生新图像时，不作为低帧率失败；必须证明抓帧和浏览器健康，而不是只看socket连接。帧率不能用面板刷新率、解码吞吐或服务器发送次数代替。

任一强制指标未达标即未通过。150–200ms触摸P95不能算通过；超过200ms属于明显优先排障项。调整门槛须记录用户决定及新版需求。

## 3. 画质与数据夹具

默认测试使用匿名数据；不公开真实设备名称、网络拓扑、IP、token或采集响应。复用现有空／紧凑／混合／密集夹具；旧夹具中的数量只是压力样例，不能写成新系统生产上限。

覆盖：CPU首次采样、真实空容器列表、容器权限拒绝、网络计数器归零、温度0°C／负值、卷满、阵列降级及维护同时发生、SMART旧值、未知模块状态词、来源清单被显式限制及遗漏数量。

单台NAS支持的所有实体必须可达。不要只凭首页上几个摘要正确就判定数据迁移完成。

## 4. 测量与观测

- 使用帧ID、事件ID和会话ID关联链路，分别记录捕获、发送、接收、解码、提交、可观察的呈现。
- 不直接相减不同主机单调时钟；若采用时钟同步估计，应给出误差范围。以同侧往返／回显和物理观测交叉验证。
- input_ack仅表示事件处理，提交显示仅表示交付给显示路径；两者都不能冒充触摸到像素反馈。
- 按项目约定使用capture-board取得实屏图像并人工检查清晰度；照片不证明fps／延迟。需要录像时先核对可用采样率，并在报告中写误差。
- 固件构建后运行静态栈检查，并观察任务高水位、内部DMA可用空间和PSRAM趋势。先查完整目标调用链再改动。
- 网络环境记录频段／信号／实际吞吐和竞争负载的匿名摘要；“支持Wi-Fi 6”不是吞吐证据。
- 主机资源报告注明CPU口径（单核百分比还是整机）、内存、平均与峰值、统计窗口。最终NAS预算在试验后确定，未确定前不能标“常驻成本可接受”。

## 5. 报告模板

每次报告复制以下字段，证据保存在本地；公开版本只保留匿名摘要。

| 字段 | 填写要求 |
| --- | --- |
| 报告ID／日期／测试者 | 唯一记录，包含时区 |
| 状态 | 未开始／通过／失败／阻塞，不使用含糊“基本完成” |
| 软件基线 | michka、网关、适配器、固件SHA／本地差异、浏览器与IDF版本 |
| 环境 | 板卡revision、显示格式、视口、图像质量、帧率配置、匿名网络条件 |
| 数据 | 夹具标识、采集周期、是否真实数据及本地保管位置 |
| 测量 | 样本数、窗口、均值／中位数／P95／最大值、时间域与误差 |
| 结果 | 各AT编号、预期、实际、证据路径、失败次数 |
| 资源 | 内存起止／峰值、队列上限与峰值、主机CPU／内存／带宽 |
| 例外 | 所有未测、延期和受限项；不能省略失败样本 |
| 结论 | Go／No-go及依据；后续动作与回退是否实际执行 |
