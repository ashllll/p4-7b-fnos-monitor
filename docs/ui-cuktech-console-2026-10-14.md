## 设计合同

目标为 ESP32-P4 7B、1024×600 横屏触控、原生 LVGL / RGB565。六页、仪表优先、多功能首页、底部导航、动态清单、实体顺序、长名称、详情返回及既有阻尼保持。网速曲线只在网络页，CPU、内存和温度趋势仍表达各自数据。单位、精度、零值/缺失/陈旧状态及采样节奏沿用当前数据合同，颜色不改变读数含义。

配色从技能中的黄色焦点、黄绿辅助通道、橙色能量和近黑底提炼；为遵循用户禁止蓝紫色的要求，不使用其蓝/青系列。以下均为本项目适配值，不声称是酷态科官方完整色表或某款设备的精确复刻。图表身份跨页稳定，正常/提醒/严重仍有独立颜色与状态文案。

| 语义 | 色值 |
| --- | --- |
| 画布 / 卡片 / 主资源底 | `#080808` / `#101010` / `#181814` |
| 顶栏与浮层 / 轨道与分隔 | `#20201C` / `#30302A` |
| 主读数 / 正文 / 辅助标签 | `#F8F8F0` / `#E0E0D4` / `#B8B8A4` |
| 焦点与 CPU 身份 | `#FFC800` |
| 内存与下行身份 | `#D8E86A` |
| 上行 / 温度身份 | `#FFB24A` / `#FFAA50` |
| 正常 / 提醒 / 严重 | `#94D278` / `#FFBB50` / `#FF8070` |

黑底占主导，亮色只用于仪表弧、曲线、焦点和关键状态。主操作为黄底深色字，次操作保留深色描边。按现有 RGB565 约束不引入渐变、光晕或额外动画；字体、首帧、缓冲、刷新和分配失败降级路径沿用工程实现，本轮未调整这些链路。
