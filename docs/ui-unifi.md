# 界面 v3：UniFi 风格重做

用户反馈 v2"还是太丑"，指定**参考 UniFi（Ubiquiti）的设计语言**重做。这是视觉体系的整体替换，
信息架构（四页、每页回答什么问题）沿用 v2 已验证的部分。

## 设计参考与依据

UniFi Network Console / UniFi OS 的暗色主题（品牌蓝 `#0559D6`，搜索已证实为 Ubiquiti 品牌色；
界面字体 Inter）。核心特征：

1. **Inter 字体**：大号 SemiBold 数字 + 小号 Medium 标签（带轻微字间距）
2. **卡片**：圆角 16、1px 细边框、内边距 18–20、留白充足（比 v2 的密集仪表盘"透气"得多）
3. **颜色克制**：整体灰阶 + 品牌蓝作强调色 + 状态色（绿/黄/红）只在状态处出现
4. **细元素**：4–6px 细进度条、1px 分隔线、2px 曲线；不搞粗边框和高对比密网格
5. **状态胶囊**：圆角全圆 + 1px 边框 + 小圆点

## 设计评审（第一轮 6/10）与迭代

视觉子代理按 UniFi 标准打分 **6/10**，三个真问题与修法：

| 问题 | 修法 |
| --- | --- |
| **层级倒挂**：主值（CK_F_NUMM=28px）比时钟还小、字重过轻 | 主值改 `CK_F_NUML`（Inter SemiBold 44）；时钟降到 17px；单位 17px 且紧贴数值（4px 间距、基线对齐）；温度写 `75°C` |
| **卡片节奏不齐、内边距偏小** | 四张统计卡统一"标签 17 / 主值 44 / 细条 / 脚注"三段，高 128，内边距 18；运行时长卡也放中性轨道占位，四卡基线对齐；健康卡右侧补"告警计数"块（大数字 + ALERTS + 6 CHECKS） |
| **图表质感不像 UniFi** | 每条轨道加 2 条细网格线；**线尾图例**（`CPU 2%` / `MEM 55%` / `1.24 MB/s`，用序列色）替代标题行色块与纵轴刻度；采样回到 1s/点（2s/点会让曲线呈规则锯齿）；面积层 20%→10% |
| 语义色不一致（数值染色与条的颜色对不上） | **数值统一白 #F5F7FA，颜色只给条**：<70% 蓝 / 70-85% 琥珀 / >85% 红 |
| 顶部"在线 · 0s"胶囊居中、0s 无语义 | 胶囊贴品牌块右侧，文案只留"在线/离线/陈旧 Ns" |
| 导航选中只有亮度差 | 指示条改品牌蓝 #3B82F6 |

保留（评审判定已像 UniFi）：深底 + 微亮卡、1px hairline + 16 圆角、细进度条、克制的品牌蓝、
页眉"设备名 + IP"、圆点+文字状态表达。
