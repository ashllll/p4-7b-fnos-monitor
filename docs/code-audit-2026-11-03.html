1. 结构与数据流

四层执行环境：固件层（网络/数据/配对/配网，不画界面）→ 共享 UI 与快照层（LVGL 9.6，只有 LVGL 线程写界面）→ 主机工装层（预览、回归、拍屏，不替代实机）→ NAS 侧 Python（数据源，TCP 8798 TLS；明文引导 8799）。
