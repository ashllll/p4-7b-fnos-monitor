# UI 动效连续性与状态视觉整改

基线 `0e02d4d`；ESP32-P4 7B、1024×600 横屏。按照本地 `ui-design-remediation` 规格实施五项修复，保留原生 LVGL、六页结构、当前主题、采集与真实历史。

## 实现

| 项目 | 当前行为 |
| --- | --- |
| 第三目标 | 当前双页自然收尾后接续最后目标；重复目标不重启，返回来源页仍从当前画面反向。自然完成、拖到端点和动画分配失败共用队列消费入口。 |
| 精简动效 | 诊断页真实开关同时控制趋势推进与导航淡入；正在播放的动画落定，后续数据照常刷新，恢复后只对新变化播放。 |
| 容量颜色 | 通过共享容量阈值保留 low/warn/high；阵列异常、旧值、无卷和权限不足仍提升关注级别，高占用不降档。八套主题分别检查各自的容量颜色。 |
| 图表量程 | 扩大立即容纳峰值；缩小候选稳定 2000ms 后使用既有临界阻尼收缩 160ms。曲线与游标共用浮点投影；网络和温度备注在收缩开始时静态发布目标。 |
| 覆盖层 | 实体详情、诊断、配网、配对统一 150ms 淡入淡出，从当前透明度反向；退场保留输入所有权，首次无凭据自动配网也走相同路径。 |

没有新增依赖、页面、主题、绘制器或采样插值。所有 UI 写入仍发生在 LVGL 线程；源读数、原始峰值、告警和历史不由动画改写。

## 主机验证

一键入口已接入新增回归：

```bash
FNOS_UI_DEVICE_CONFIG="$PWD/build-ui-remediation/config/sdkconfig.h" \
  bash tools/preview/run.sh out-ui-remediation
```

- 完整六页状态、字形、格式说明符残留、父子边界、可点击重叠、对比度、清单和受控分配失败恢复通过。
- API 转场 153 帧：首次入页、重复目标、快速反向像素、最新第三目标接续、拖到端点、原生裁剪命中与冻结历史通过。响应探针的快速重定向完成时间为 120ms。
- 原生指针及纵向滚动 322 帧通过，采样步长 16ms；该步长不是设备帧率。
- 四类覆盖层 25 帧、首次自动配网 3 帧、精简与恢复的五图采样 12 帧通过。
- 图表几何回归验证 2000ms 等待、连续单调收缩、候选改变、中途扩大、两端范围、窄量程浮点精度、旧值、隐藏、清空和落定。产品网络页另通过真实历史峰值进窗／离窗，验证量程和备注更新时刻。
- 八套主题分别运行容量阈值边界、异常阵列、旧值、无卷和权限不足组合。数字／仪表与三组趋势页持续输入回归通过。
- ASan／UBSan 图表、覆盖层、API 转场和原生指针／纵向滚动通过；`detect_leaks=0`，没有完成泄漏检测。

逐帧播放器位于本地排除目录：`tools/preview/out-ui-remediation/motion/index.html`、`overlays/index.html`、`reduced/index.html`。已实际查看转场、覆盖层和量程中间帧，不仅检查退出码。

## 固件与审查

使用本机已安装的 ESP-IDF 5.5.5、P4 GCC 20260121 和 Python 3.9 环境，独立 `build-ui-remediation` 构建通过；保留旧 `build` 缓存。产物只留本地，未发布。

```bash
# 在对应 IDF 环境下执行
./idf.sh -B build-ui-remediation build
python3 tools/stack_check.py --elf build-ui-remediation/fnos_monitor.elf
```

静态栈检查全部入口在预算内：主任务 5312/16384 B，LVGL 任务 5328/12288 B。结果是静态下界，不覆盖全部函数指针和中断嵌套。

独立审核发现并修复了端点收尾遗留队列、非默认主题容量色被覆盖，以及覆盖层退场底栏穿透。Clang 分析报告的四项告警在原基线重跑得到相同结果；未将已有告警写成已修复。
