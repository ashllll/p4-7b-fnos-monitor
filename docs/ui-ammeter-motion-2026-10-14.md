# 电流表式遥测动效

本文件记录动效实现阶段；决策理由见 [ADR-0002](adr/0002-continuous-telemetry-motion.md)，后续数据可信度补丁及最终固件验证见 [并行缺陷复核](ui-post-motion-audit-2026-10-14.md)。下文产物和采集统计保留为该阶段证据。

## 合同与范围

目标为 ESP32-P4 7B、1024×600 横屏、LVGL 9.5 / RGB565 / TRIPLE_PARTIAL；不开展窄屏与竖屏迭代，按用户要求不拍照。沿用酷态科视觉语言、真实采样历史与原生触摸路径。只改变显示运动，不改网络采样、阈值、告警、零值、单位或设备清单。

六页中的连续读数、环表、容量条、温度条共用临界阻尼模型。单位或状态改变、缺失、离线、首次有效读数与隐藏对象立即发布，不能从假零值扫入。图表横向仍按真实时间线匀速滚动，不给时间轴加缓动；网速曲线仅在网络页。实体详情是打开时的冻结快照，不伪造持续活动。配网与配对的步骤、按键和告警信息保持即时语义反馈。

## 参数与实现

默认静止阶跃响应采用 `1-(1+ωt)exp(-ωt)`，阻尼比为 1。共用名义响应时长 450 ms、因子 8（自然频率约 17.78 rad/s）；静止起步约 94 ms 追到 50%、219 ms 追到 90%、373 ms 追到 99%。数字微小位移在 450 ms 收尾；环表与条形继续保留低于可见尺度的尾段，误差和速度均足够小时停止，最迟 900 ms 精确落定。Kconfig 可调时长与因子，0 ms / reduced-motion 直接落定。

中途更新从当前显示位置和速度重定向，不累积目标队列，不重置速度。反向时允许短暂惯性继续，但环表/条形始终受合法量程约束；不要把“临界阻尼”误述成任意初速度下绝不过冲。末帧精确落定，真实数据与历史不插值。

共享 spring 闭式求值避免数值积分在丢帧后失稳；用 513 个 float（约 2 KiB）共享指数查表和线性插值，仅初始化时计算一次指数。查表起步位移系数限幅，避免长时长配置出现亚像素反向起步；数字每帧共用系数。原生 bar/arc 使用每显示单位 100 个内部刻度，避免整百分比跳格，标签仍显示原单位。状态与颜色使用原始数据，不能用滞后的绘制值决定告警。可选动画分配失败直接显示目标，销毁对象同时取消回调并释放状态。

## 验证

- PC 并行比较线性、smoothstep、quintic、归一化临界阻尼及连续二阶响应，覆盖 100 / 200 / 1000 ms 更新与中途反向，并完成两轮固定源码复核与 float32 查表评估。PC 未编译项目或操作设备。
- 默认查表静止阶跃误差折算 300 px 满幅位移约 0.037 px。PC 指出的 550 / 1000 ms 起点微小反向已修正，实际 C 自检覆盖全部 1–1000 ms 整数时长；不把该阶跃误差作为任意初速度的统一上限。
- 数字/仪表位置与速度重定向、同目标不重启、跨名义时长的分段一致性、首次/隐藏/禁用/分配失败/删除、单位切换立即发布自检通过。ASAN / UBSAN 数字与仪表回归通过。
- 完整 1024×600 状态审计、密集设备及分配失败恢复通过；六页共 234 张动效帧、24 组数字与单位锚点回归通过。已检查实际渲染的起点、中途和尾帧。环表数字固定中心并按“100”的实际字宽保留稳定绘制区，运行时长与容器读数也使用稳定宽度，避免数字变窄时退回直接切换；辅助单位固定位置。
- 手势切页 140 帧、重复目标 96 帧、首次系统页 71 帧通过。页面方向与触摸跟手路径继续使用既有快速临界阻尼，数据运动优先级低于输入。
- RISC-V GCC `-fanalyzer` 检查 `uk_meter.c`、`uk_number.c`、`uk.c`、`fnos_ui.c`，无诊断；ESP-IDF 构建通过，应用 `0x6bf250`，应用分区余量 25%。新 ELF 静态栈下界：主任务 4864 / 16384 B、LVGL 4832 / 12288 B，全部受检入口在预算内；静态检查有间接调用及中断覆盖边界。
- 没有拍照。实机手感仍由用户肉眼体验判断，主机动效及数学模拟不能代替实屏评价。最终固件已烧录：引导、应用、分区表三项写入哈希校验通过，IDF flash 退出 0。20 秒串口观察最后记录累计成功采集 291 次、失败 0 次，未见 panic、栈保护异常或错误级日志；短时观察不代表长期稳定性或实屏手感验收。串口 helper 把 `fail=0` 统计字段识别成错误返回 1，已核对实际日志。

模型参考 [MIT 临界阻尼阶跃响应](https://web.mit.edu/2.010/www_f00/psets/hw7_dir/hw7_sol.pdf)；原生动画调度参考 [LVGL 动画文档](https://lvgl.io/docs/open/9.3/details/main-modules/animation.html)，实际接口以项目 LVGL 9.5 源码为准。
