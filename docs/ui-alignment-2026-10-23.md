## 已确认并修复

首页圆环原来把数字的三位数遮罩和百分号一起居中，遮罩里的数字却向右对齐。实际渲染中 `0` 偏右 16.5 px、偏上 2 px。现在数字独立以圆心为锚点，保留最大量程的动画遮罩；垂直补偿由字体字形度量计算，百分号独立居中放在下方开口。对 `0 / 9 / 37 / 99 / 100` 的最终像素检查，横向误差不超过 1 px，纵向为 0 px。

行内数字和单位原先使用固定底部留白，在 20、32、44 数字字体与单位字体之间留下基线误差。共享构件及页面创建代码改为按字体基线差计算单位留白，只在创建时执行，不增加每帧布局工作。

扩大检查至 TB 单位后，还复现了首页存储容量从 `17.8` 变为 `99` 时，单位左移 16 px。该读数现复用已有的最小宽度预留；常见整数、小数进位期间单位不动，超出预留的真实读数仍可扩展。无容量数据时提示独占该行，避免数字预留宽度挤掉完整说明。

## 验收范围

逐页查看了总览、存储、网络、系统、温度、告警画面，检查主数字、容量三列、速率与延迟、设备温度值、清单右边缘和告警等级列。六页动效回归覆盖 28 组数字/单位，验证整数、小数、负数、零值、缺失值的锚点和单位位置；其中同行单位的基线差为 0 px，圆环单位按独立行检查。

`PREVIEW_REFRESH_WORK` 增加最终像素的圆心检查，保留 `100 ↔ 9` 遮罩不裁切回归。原圆环安全间距断言改为检查数字遮罩，容器现覆盖整个圆环，仍保留三位数内侧余量要求。

完整主机预览还覆盖缺字、标签溢出、子对象越界、点击重叠、动态硬件清单与内存失败恢复。当前原生指针切页、重复目标、快速反向及响应预算回归通过；GCC analyzer、设备构建和静态栈检查分别记录于本地证据目录。

动效终帧比对曾只在顶栏跨分钟时失败，差异为时钟区域 112 个像素。主机预览现在固定每次运行的墙钟时间；重定向仅作用于预览中的 UI 编译单元，设备时钟和遥测时间不变。修正后的 328 帧原生指针回归通过。
