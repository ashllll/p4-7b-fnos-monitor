# 原版 michka 在外部主机运行，P4 保留为远程触控终端

用户先选择原版michka，随后明确继续使用现有P4，最终确认“NAS／电脑运行，P4接收画面并回传触摸；先验证流畅度”。因此接受外部浏览器渲染和P4远程显示方向。此处accepted指产品架构方向，不表示实现或性能已经通过。

## 取舍

原生LVGL重做可以复用现有本地动效，但不满足用户选择原版网页的目标；更换浏览器终端也不满足保留开发板要求。外部渲染同时保留二者，代价是新增常驻主机依赖、带宽、编码损失、触摸延迟和恢复链路。

必须先验证真实触摸到屏幕反馈，未通过不扩大完整NAS数据迁移。渲染主机停止时，本地恢复入口仍须可用。具体传输方式由[ADR-0009](0009-jpeg-remote-display-poc.md)提议；现有遥测语义继续遵循[ADR-0003](0003-module-freshness-and-reading-presence.md)。

## 与现有决策的关系

对“未来远程模式”的主画面，此决定改变[ADR-0001](0001-native-instrument-ui.md)由LVGL原生构件绘制全部页面的方向；现有固件及新模式本地连接／恢复UI仍使用原有实现。迁移未验收前不将ADR-0001整体标为失效，不删除旧六页，不追认旧固件性能等同于新链路性能。

见[PRD](../michka/PRD.md)、[迁移计划](../michka/MIGRATION.md)。
