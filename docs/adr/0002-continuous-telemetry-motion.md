# 连续遥测保留位置与速度，使用共享临界阻尼

2026-10-20：求解实现、默认阻尼和呈现节拍由 [ADR-0005](0005-library-springs-and-attached-cursors.md) 替代；连续重定向、真实数据和显示状态分离的合同继续有效。

用户希望数值变化呈现老式电流表的平顺惯性。相较每次采样重新启动固定起止缓动，数字、环表和条形共用临界阻尼响应，中途更新以当前显示位置和速度重定向，同目标不重启、不排队；数据采样与真实历史保持原值。固定缓动会在连续目标更新时反复重置速度，故采用可连续重定向的二阶响应。

默认名义响应为 450 ms、阻尼因子 8（阻尼比 1，自然频率约 17.78 rad/s）。数字在名义时长结束，环表/条形以位置与速度双阈值落定，最迟 900 ms；数字保留独立的 600 ms 共享呈现节拍，采样和显示刷新周期不因此减慢。参数集中配置，不能在页面里另设一套曲线。首次有效值、单位或状态变化、旧值、缺失及离线采用即时语义发布；图表横向时间轴继续线性运行，触摸导航保持既有快速响应。

实现保留原生 label/bar/arc 接口，原生仪表每显示单位使用 100 个内部刻度；共享指数查表约占 2 KiB，减少逐帧指数计算。代价是额外运动状态与生命周期管理，分配失败必须直接显示目标，删除对象必须同步取消回调并释放状态。临界阻尼不代表任意初速度下绝不过冲；反向可保留短暂惯性，输出仍受合法量程约束。

实现入口为 [`uk_meter.c`](../../components/fnos_monitor/ui_kit/uk_meter.c)、[`uk_spring.h`](../../components/fnos_monitor/ui_kit/uk_spring.h) 与 [`uk_number.c`](../../components/fnos_monitor/ui_kit/uk_number.c)。参数比较、数值误差边界及实际回归见 [动效记录](../ui-ammeter-motion-2026-10-14.md)。

## 2026-10-15 参数重调

用户报告动画慢且不流畅并要求修复，因此重新核对上述默认时长。连续重定向与临界阻尼的架构决策保持有效；默认响应调整为 180 ms、环表收尾上限 360 ms，阻尼因子仍为 8（自然频率约 44.44 rad/s）。600 ms 数字呈现节拍保持不变。此前的 450/900 ms 为历史参数，当前节拍修正与验证边界见 [2026-10-15 记录](../ui-motion-cadence-2026-10-15.md)。
