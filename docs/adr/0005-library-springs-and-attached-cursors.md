# 复用 Damped Springs，并把游标附着在仪表和曲线上

用户要求保留圆环、条形和图表，全部增加直接贴在图形上的游标，并采用已有算法实现老式指针电流表的惯性。这替代 ADR-0002 的自写临界阻尼求值和指数查表，继续保留位置、速度、真实采样与显示状态分离的合同。

采用 [Ryan Juckett Damped Springs](https://www.ryanjuckett.com/damped-springs/) 的完整开源实现，仅适配 C99 语法。原始许可、版本标识和源码摘要见 [第三方说明](../../components/fnos_monitor/ui_kit/third_party/README.md)。接口统一转换秒与毫秒，数字、圆环、条形、入场和页面切换共用求解器。同参数的相邻求值复用精确系数，不再维护自写曲线或近似指数表。

收到实机反馈后，遥测默认响应调整为 600 ms、频率因子 8、临界阻尼比 1.0；数字恢复 600 ms 共享呈现节拍，避免每次采样都重启视觉变化。默认曲线的透明度 10%→90% 实测为 252 ms，原 300 ms / 0.85 配置只有 100 ms。以上由 Kconfig 控制；源采样、历史、告警判断与手势时长不变。圆环数字按量程最大值与实际字体测量固定遮罩，数字字形居于圆心，百分号独立位于下方开口。文本宽度变化时，退场字形的起点和终点同时转换到新坐标系，避免淡出途中横向跳动。

圆环游标复用 LVGL 原生 knob；图表复用原生 chart cursor，定位到最新可见曲线上的点；条形在 LVGL 实际 indicator 几何上画短标记。游标不会占据布局或产生独立运动状态。图表横轴仍对应真实时间、匀速滚动，不把历史插值成虚构测量。曲线最新点暂在视口外时，只在可见线段上插值游标的绘制坐标。

首值、缺失、旧值、单位变化与精简动效即时发布。不存在的曲线值不显示游标，隐藏序列不显示游标；合法零值保留起点游标。身份颜色和告警颜色来自真实数据，不能由回摆决定。

代价是每种新时间步要调用标准数学函数，换取已知来源和可变时间步稳定性；去掉约 2 KiB 指数表及独立切页查表。主机逐帧、分配失败、反向和栈验证与实机性能验收分别记录，见 [本轮记录](../ui-ammeter-cursors-2026-10-20.md)。
