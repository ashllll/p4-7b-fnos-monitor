# 继承 michka 上游许可，按代码来源保留许可范围

用户明确要求迁移文档强调继承上游协议。已核对固定上游提交的LICENSE声明CC BY-NC 4.0。因此michka原始材料及本项目对其衍生修改继续采用CC BY-NC 4.0，保留作者、版权、许可和修改记录，不转标为当前仓库的Apache-2.0。

## 为什么需要单独决策

现有仓库自有代码采用Apache-2.0，上游还有各自许可的第三方依赖。若只沿用根LICENSE或一键替换所有文件声明，会错误描述权利范围；若不保留变更来源，后续升级和发行也无法判断归属。

CC BY-NC不含SA条款。相同许可继承是本项目主动采用的政策，不能误写成协议本身要求ShareAlike。对于新增原创迁移模块，计划在作者有权授权的范围内采用CC BY-NC 4.0；复用既有Apache代码、库或字体仍保留原通知和相应条件。

## 后果

发行物必须附来源／版本、修改清单、署名、非商业限制和第三方许可清单。不能把含michka的包宣传为Apache-only／MIT-only或无商业限制；需要超出原许可用途时先取得相应权利人授权。

根LICENSE和已有独立发行物不在本次重新许可范围。混合来源或归属未明时记录为发行未决项，不能靠换目录解决。具体范围、模板与门槛见[许可政策](../michka/LICENSING.md)及[原样上游声明](../michka/UPSTREAM-LICENSE.txt)。
