# 所有遥测趋势使用更强的流水平滑

用户要求继续加大平滑度，覆盖所有动态线条。本决定替代 ADR-0006 的网络独占范围与单次平均，保留其 D3 curveBasis 几何、匀速时间轴、原生 LVGL 绘制和数据／显示分离。

CPU、内存、首页温度、温度页和网络趋势统一启用 flow。显示滤波复用成熟的[双重移动平均](https://www.dspguide.com/ch15/4.htm)：两次矩形均值的卷积等价于三角核，起落比单次平均更柔和。默认每次 9 点，合并为 17 点权重 `1,2,...,9,...,2,1`。直接计算既有原始环，不引入新环、动态分配或逐帧滤波状态；窗口随现有点数收缩，缺失立即切段并对有效部分重新归一化。完整窗口下与两次平均等价，起始与缺失后使用部分核归一化。

既有 `FNOS_UI_FLOW_SMOOTH_SAMPLES` 表示每次平均点数；1 禁用数值平滑，几何样条仍保留。完整默认核的趋势延迟约 8 个采样周期，接受这个代价换取更柔和的流水形态。实时数字、圆环、容量条、原始峰值、采样数量及告警仍使用原始数据，不把显示近似回写为测量。

所有产品趋势显式启用 flow，底层普通趋势模式保留用于既有调用合同和对照。水平推进保持真实时间的匀速滚动，游标沿同一条可见样条定位，精简动效与旧值合同不变。

验证须覆盖同数据前后渲染、短波衰减、阶跃单调跟随、原始数据完整、常量／独立序列、缺失、游标像素与设备运行。记录见 [全曲线平滑](../all-trend-flow-motion-2026-10-21.md)，主机结果与物理屏幕结果分别列出。
