# 指标身份色与当前状态色分离

早期候选让当前占用率同时改变圆弧、读数和整条历史曲线，造成红黄面积过大，也让旧历史被当前值重新解释。用户随后提供 CUKTECH ULTRA 参考图，要求黄色改为蓝色、粉红改为朱红，并保持全界面一致。

继续使用 ADR-0001 的共享原生 LVGL 构件，由 `uk_pal_t` 统一表面、文字、指标身份、健康和占用状态颜色。主读数保持高对比白色；历史曲线保留指标身份；当前负载只改变圆弧与进度条。颜色同时配合数值、状态文字和控件形态，不能单独承担异常含义。新鲜度仍按 ADR-0003 独立降灰。

占用率通过 `uk_pct_color(float)` 使用未取整的输入与已有 Kconfig 阈值；负数和非有限值返回不可用色。阈值判断与颜色值分离，首页、存储摘要和卷行共用同一判断。颜色属于主题，不能在页面复制阈值或写死色值。

默认主题、主机预览初值及未知主题回退统一为 `cuktech-console`；历史预置名称继续可选。现有 sdkconfig 保留用户值，升级需显式选择新主题。当前蓝色兼用于焦点和提醒，由操作控件与状态文案区分；这是用户指定的视觉取舍。

2026-10-22 更新：公共默认主题已迁移为 `michka`，主机预览初值与未知主题回退同步；本条关于指标身份色与当前状态色分离的规则继续有效，默认主题名称以 [michka 石板灰](../ui-michka-slate-2026-10-22.md)为准。

本决策补充 ADR-0001/0003，不替代它们。精确色值、图册、验证与发布边界见 [ULTRA 设计](../ui-cuktech-ultra-2026-10-14.md)和[发布归档](../ui-ultra-release-2026-10-14.md)。
