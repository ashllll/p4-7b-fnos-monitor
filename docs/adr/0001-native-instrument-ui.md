# 通过共享原生 LVGL 构件统一横屏仪表界面

2026-10-22 关联更新：[ADR-0008](0008-michka-remote-display-direction.md) 接受未来远程模式由原版 michka 绘制主画面的方向。完整远程客户端尚未交付和验收，本记录继续适用于现有原生固件；本地连接／恢复界面仍可复用 LVGL。本记录的历史布局描述不替代当前源码。

用户要求先通过图表和仪表理解设备状态，文字作为辅助，同时提高首页功能密度。继续使用 `fnos_ui.c` 与 `ui_kit` 原生构件，通过共享主题、数字、对象行和输入控件覆盖六页、详情、诊断、配网与配对；默认采用 CUKTECH 仪表语言，替代原 UniFi 行式清单优先的呈现方向。由共享构件实现，避免各页形成独立皮肤和状态逻辑，保留现有原生布局、触摸与审计能力。

当前产品边界固定为 ESP32-P4 7B 的 1024×600 横屏，使用全宽内容和底部导航；网速曲线只在网络页。动态设备数量、完整名称、清单重排与滚动可达继续自适应，屏幕范围的收窄不成为裁剪设备的依据。首页采用 3×3 九张等宽等高卡，将当前圆环指标与独立历史图表分开，并增加温度趋势和独立卷比较；完整长诊断通过详情访问，减少常态小字与重复信息。

代价是共用构件修改需要同时验证主页面、输入键盘、详情和异常状态，不能仅凭一张首页样图判定完成。字体采用原生像素尺寸生成，关键数字为 Chakra Petch Bold 32/44 px、4 bpp，中文为现有 Noto Sans SC 字库；没有实施整套中文点阵替换，也没有完成字体实屏 A/B。

设计和验证见 [CUKTECH 界面合同](../ui-cuktech-2026-10-14.md)；保留原生 LVGL 管线是对 [既有架构](../ui-v12-lvgl-native.md) 的延续，本次没有重新执行历史 JSON/MVVM 管线的移除。
