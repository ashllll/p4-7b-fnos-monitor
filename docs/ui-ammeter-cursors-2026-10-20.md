# 库阻尼与附着游标

本轮在开发目录实现，保留原有圆环、条形和趋势图。游标直接附着在图形上：圆环用原生 LVGL knob，条形在实际填充末端画短标记，趋势图为每条可见序列设置原生 chart cursor。游标不占据布局，不维护另一套动画坐标。

## 算法与显示合同

采用 [Ryan Juckett Damped Springs](https://www.ryanjuckett.com/damped-springs/) 的完整实现，保留原许可，做 C99 语法适配；来源与摘要见 [第三方说明](../components/fnos_monitor/ui_kit/third_party/README.md)，取舍见 [ADR-0005](adr/0005-library-springs-and-attached-cursors.md)。

- 遥测默认 300 ms、频率因子 8、阻尼比 0.85。静止阶跃约 0.6% 回摆，仪表输出限制在量程内。参数来自 Kconfig。
- 数字、圆环、条形、透明度和切页共用库求解器；透明度与切页使用临界阻尼。相同时间步和参数复用精确系数，移除旧指数查表。
- 新目标继承当前显示位置和速度，重复目标不重启；首次有效值、缺失、旧值、单位改变和精简动效立即发布。数字默认不再额外等待独立的 600 ms 呈现节拍。
- 圆环数字按量程与字宽预留稳定区域；网络、温度和 KPI 的常见进位按实际字体测量最小宽度，较大真实值仍允许扩展。读数靠近单位一侧对齐。
- 图表横向滚动继续表达真实采样时间。游标只插值可见线段的几何位置，不改写历史值；无样本、断点、隐藏序列与清空状态不显示不存在的曲线端点。
- 快速打断切页后反向甩动，按本次手势的速度方向收尾；缓慢拖动保留距离阈值判定。

| `PREVIEW_NUMBERS=1` | 欠阻尼、临界、过阻尼、拆分时间步、回摆、反向速度、重复目标、隐藏、精简动效、分配与删除通过 |

| `PREVIEW_MOTION` | 原生触摸、纵向滚动隔离、快速反向、首次入页、重复目标、终帧像素和历史不被伪造通过 |
