### 1.1 外壳几何（所有稳定帧实测）

### 1.2 与 lead 复核口径的差异（需对齐后再引用）

Lead 复核给出的“三行 165 / 137 / 122”中：

- **165 / 165 / 165** 是三个行容器（`uk_row_box`）的实测高度：barmap 9 张卡全部 `h=165`（y=60/237/414），bands 三行 `y=[60,224] / [237,401] / [414,578]`。像素在 x=250 复测：三行卡底色带 60–224、237–401、414–535，**第二行底边在 401，不在 374**。
- **137** 是第二行里 CPU趋势/内存趋势两张卡的 `min_height`（bands `minh=137`），不是行高。
- **122** 是第三行卡片被 535 截断后的**可见高度**（414–535），不是行高。
- 结论不变：三行等高要求被破坏（可见高度 165/165/122），且第三行 43px 在首屏外；但定性必须落在 **page 视口截断** 与 **行高被最大卡钉死**，不能写成“第二行只有 137”。

## 6. P2（审计/证据面）

### P2-1 `audit_bounds` 对可滚父跳过直接子对象，页级溢出全部漏报
