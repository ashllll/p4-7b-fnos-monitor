## 必须单独验收的边界

- **真实内存耗尽**：当前 LVGL 动画和 timer 分配失败先触发 `LV_ASSERT_MALLOC`，设备配置的处理器是 `while(1)`。调用者收到 NULL 时的回退／重试和数字控件专项注入已测，不能证明真实 allocator 耗尽可恢复；未关闭全局断言或修改 managed 依赖。
- **持久化与回退**：NVS 旧无标记混代、旧固件回退、真实 Flash 掉电仍待验证。配置候选采用私有临时文件和文件 fsync；协作 writer 使用同一 flock 与 revision CAS。非协作／旧 writer 可绕过版本规则，目录掉电持久性未证明。
- **TLS 与权限**：候选证书校验、备份恢复及活跃 context／公有身份快照已覆盖；两个文件 replace 不构成掉电原子。非协作 writer、真实证书确认／配对／撤销和 NAS 安装用户／目录权限仍待验收。Socket 0600 允许 root 与所属用户，不能称只有网关可访问。
- **请求与退出**：整连接 32 槽、30 秒绝对 watchdog 和共享排空预算已实现；短计时夹具没有实际等待生产 30 秒。退出收据区分进程消失与正常收尾；flock、fsync、不可中断后端 IO 和 OS 调度没有硬退出上界。PID／命令路径及 Unix inode 归属检查仍存在同 UID 竞态，非 pidfd 或隔离保证。
- **历史与数值**：不透明游标、reset／回填、实时保留及数值边界已做生产片段回归；仓外旧调用者兼容、设备锁时延、极值标签长度与所有控件完整渲染未证明。
- **容量与性能**：0.80 容量目标、30% 性能目标和真实 72 小时长跑尚未闭环；主机矩阵数量不是生产设备上限。
- **真实界面与交付**：浏览器 file 页面已被安全策略拒绝，未转发 HTTP 或换表面绕过。管理页／遗留页视觉、物理屏幕、真实 NAS 升级／卸载和新的 FPK 均需独立验收。
