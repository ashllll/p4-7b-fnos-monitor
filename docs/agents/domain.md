# 领域文档约定

本项目按单上下文维护领域文档，固件和 NAS 配套应用共用监控领域词汇；当前不需要 `GLOSSARY-MAP.md`。

探索、设计或评审前，先读根目录 [GLOSSARY.md](../../GLOSSARY.md)，再从 [ADR 索引](../adr/README.md) 读取当前工作涉及的决策：共享界面为 ADR-0001，遥测动效为 ADR-0002，读数存在性与新鲜度为 ADR-0003，颜色身份与状态分离为 ADR-0004。方案与已接受 ADR 冲突时，应明确指出冲突及重开的理由，不能静默覆盖。

术语表只写领域含义；实现选择和真实取舍进入 ADR；页面行为、参数、测试和设备证据进入各自的设计／验证记录。改变既有决策时新增顺序编号 ADR，并在原记录标注替代关系；普通修复不要求新增 ADR。

当前默认配色及发布验证见 [ULTRA 归档](../ui-ultra-release-2026-10-14.md)。当前界面合同见 [CUKTECH 设计](../ui-cuktech-2026-10-14.md)，连续阻尼参数见 [动效记录](../ui-ammeter-motion-2026-10-14.md)，本轮最终缺陷回归及烧录窗口见 [验证记录](../ui-post-motion-audit-2026-10-14.md)。历史文档的窄屏、字体、候选产物和未烧录描述只适用于各自阶段；当前只迭代 1024×600 横屏。

主机测试、构建、烧录校验和实屏验收分别记证据，不能互相替代。真实配置、设备清单、接口响应、原始日志及个人固件留在本地排除路径；公开文档使用模板和匿名夹具。领域约定不扩大设备操作、提交、推送或外部写入授权。
