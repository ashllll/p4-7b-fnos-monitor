# UniFi 深色候选版 · 2026-10-14

> 历史归档：本页记录当时的候选、命令和验证，不代表当前默认版；当前源码无法保证复现旧图。最终方案与发布情况见 [ULTRA 设计](ui-cuktech-ultra-2026-10-14.md)及[本轮归档](ui-ultra-release-2026-10-14.md)。

用户要求参考 UniFi 深色界面，将全部屏幕迭代一版用于比较。本轮使用 `unifi-ui-design`，在现有原生 LVGL 共享主题和构件中实现候选版。默认 `cuktech` 及上一版暖中性图册保留；通过 `unifi` 主题选择候选版，没有替换 ADR-0001 的默认产品方向。

## 参考与项目适配

界面观察基线为技能中的 L1：2026-10-12 实测的 UniFi Network 10.6.106 / UniFi OS 5.1.33 深色桌面界面，视口 2205×1175 CSS px、DPR 2、鼠标输入，发布通道及缩放未确认。借用其中中性工作区、独立顶栏、低对比结构、高对比读数、清单分隔线和覆盖式详情的关系，不声明精确复刻，也不声称该版本为最新版。

[官方 Traffic Flows 文档](https://help.ui.com/hc/en-us/articles/32201256219799-Traffic-Flows-and-Traffic-Logging-in-UniFi-Network)于本轮重新读取，确认列表与属性面板的关系。该文档不提供完整颜色、字体或动效规范；本项目不增加会话采集或 UniFi 管理能力。

本项目仍为 1024×600 横屏触控、NAS 仪表优先、六页和底部导航。保留多功能首页、长名称与动态清单、详情返回位置及既有临界阻尼。网速曲线仍只在网络页；CPU、内存和温度趋势保留各自量纲。

遵循用户先前“不要蓝紫色”的要求，交互强调改为中性白，图表方向使用柔和绿与琥珀色。所有色值、8 px 卡片圆角、4 px 控件圆角均为项目适配值，不标为 UniFi 官方 token。RGB565 下选用适合量化的中性表面阶梯；实际面板色彩仍待验证。

共享主题增加圆角与清单样式字段。候选清单使用透明行和底部分隔，保留原有内边距、最小行高与滚动可达；其余五套主题使用原有圆角和对象磁贴。主操作为白底深色字，次操作为深灰描边；风险操作继续使用独立严重色。

## 渲染与验证

完整候选图册见 [15 张原生界面](images/ui-unifi-dark-2026-10-14/README.md)，可与 [上一版图册](images/ui-2026-10-14/README.md)比较。覆盖总览、存储、网络、系统、温度、告警、健康体检、卷/容器详情、诊断、Wi-Fi 扫描/输入、配对码/证书和夜间总览；数据均为匿名模拟夹具。

```sh
KK_PALETTE=unifi bash tools/preview/run.sh out-unifi-dark-20261014
bash tools/preview/run.sh out-warm-preserved-20261014
```
