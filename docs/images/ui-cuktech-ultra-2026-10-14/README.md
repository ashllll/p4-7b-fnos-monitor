# ULTRA 黑底蓝青参考版 · 2026-10-14

纯黑背景、白色主读数、冰青与蓝色强调、局部橙色身份标识；严重异常为朱红。21 张原生 LVGL 1024×600 图采用匿名夹具，含六页、输入与详情、夜间及三档占用率。这些图是主机渲染，不代表实屏验收。
