## 复现

从仓库根目录执行，先按 [项目说明](../../../README.md#快速开始) 激活 ESP-IDF 环境：

```bash
./idf.sh build
bash tools/preview/run.sh out-warm-20261014
```

公开图片直接从该次输出复制并按页面命名，未修图、裁切或重绘 UI。完整流程生成 105 张状态图，同时执行几何、字形、格式残留、触控遮挡、对比度、清单和分配失败恢复检查。这里只选择 15 张用于产品介绍；未列出的状态仍在完整主机检查内。

[manifest.json](manifest.json) 保存源基线、夹具 SHA-256、实际 UI 配置、文件映射与每张 PNG 的 SHA-256。不同配置或时间相关夹具可能使重渲染的数值／像素变化；校验值用于验证本次发布文件，而非承诺任意环境逐字节复现。
