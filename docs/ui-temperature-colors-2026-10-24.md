# 温度区间颜色修复

用户确认按正常、偏热、高温三个温度区间区分颜色。沿用共享 Kconfig 阈值，当前本地配置为 75°C 关注、80°C 高温；不修改采集或告警阈值。

- 正常温度由共享 `uk_temp_color()` 返回主题正常色，不再返回普通文字灰色。
- 温度页顶部最热读数、设备最大值、展开通道、状态点和设备条使用同一严重度。当前主题为正常绿、关注蓝、高温朱红；其他主题使用各自现有状态色。
- 旧值保持文字降灰、条形关闭色；无数据仍显示占位。趋势曲线保留身份色，不由当前温度重染历史。
- 本轮按用户新要求，让温度页顶部读数也表达当前严重度，替代该处沿用白色主文本的历史样式；其余指标读数策略不变。

`verify_temperature_colors()` 已接入完整主机预览和 `PREVIEW_DATA_MOTION=temperature`。先在旧实现上复现颜色断言失败，再验证负温度、0、低于关注阈值、恰好关注、中间值、恰好高温、高于高温、昼夜、旧值和同屏三个设备的不同温度档位。终态文本先跨过既有 600ms 数字呈现节拍，不修改生产节奏。

```bash
FNOS_UI_DEVICE_CONFIG="$PWD/build-ui-remediation/config/sdkconfig.h" \
  bash tools/preview/run.sh out-temperature
PREVIEW_DATA_MOTION=temperature tools/preview/build/preview /tmp/fnos-temperature
```

完整状态和八套主题分别检查字形、格式残留、几何、点击重叠与对比度；固件使用既有 ESP-IDF 5.5.5 独立构建目录，另跑静态栈检查。本机预览已查看三档同屏样张；截图仅含匿名 fixture，保存在本地排除目录。
