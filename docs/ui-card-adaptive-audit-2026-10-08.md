# 配对卡片与全页面自适应检查

基于已有 LVGL / ui_kit 界面，使用 interface-design 与 Refactoring UI 的 apply-consistent-spacing。
复用当前配色、字体及 UK_CARD_GAP / UK_ITEM_GAP 间距令牌；没有新增 UI 框架或修改采集、配对协议。

## 配对页

配对不再套在一张整页大卡片内：顶部状态卡，正文按阶段显示步骤卡、配对码与键盘卡、说明或连接状态卡、
证书指纹卡。正文卡片按自然高度排列，根据码槽、键文字与触控尺寸、四行指纹的实际宽度选择单列或双列。
指纹字号按四行内容共同决定，所有指纹保持完整。底部关闭、取消、接受、解除配对按钮独立于滚动正文，
宽度取文字内容和主题触控下限。阶段变化和重新打开时复位正文滚动。

正常七英寸屏使用左右卡片；窄屏指纹阶段转为单列，短屏滚动查看正文。解除配对仍保留原有二次点击确认。

## 页面覆盖

| 页面或面板 | 排布及自适应机制 | 检查内容 |
|---|---|---|
| 总览 | Flex 分配主仪表、内存与容器卡、网络与容量卡 | 主读数、单位、状态降级、卡片边界；次要元信息允许省略 |
| 存储 | 容量摘要，存储卷、阵列与磁盘活动的池布局 | 行距、列表重排、滚动到底、容量与百分比 |
| 网络 | 根据数字、单位和标题测宽选择列数，四指标均衡分行；高度按副文字换行计算 | 数值单位完整、长网卡名换行、趋势与信息卡可达 |
| 系统 | 摘要、容器与硬件温度卡、告警卡按可用宽度重排 | 8/16 容器顺序、列表滚动、温度分组、告警长文字 |
| 温度 | 设备分组和通道展开，池列数随可用空间变化 | 满传感器列表、展开收起、状态与刷新稳定性 |
| 配对 | 独立状态卡与正文卡，单列或双列；正文滚动，页脚固定 | 首次及重复进入、12 键可达、四行指纹、全阶段及退出导航 |
| 配网 | 阶段内容、按文字宽度排列的页脚；键盘保留自然行高，正文纵向滚动 | 扫描/输入/连接中/成功/失败/重试按钮、41 键可达及页脚不位移 |
| 采集诊断 | 键和值按字体预算分栏，值可换行，正文可滚动 | 长协议/错误/采集段信息、诊断退出与模块导航 |

五个监控页增加纵向滚动兜底，确保短视口的自然内容可访问；顶栏、底栏和横向切页规则保持原有结构。
内容卡片可以在滚动视口边缘部分露出，这与对象互相覆盖或不可访问的裁切分别检查。

## 实际发现并修复

1. 配对原先固定侧栏占比及按钮宽度，不能统一按卡片排布；现在按真实内容预算排布。
2. 640×480 的网络信息卡底边越过页面底边：使用页面纵向滚动兜底。
3. 480×800 的网络副文字需要两行，而固定指标行高装不下：按实际字体和换行后的自然高度计算。
4. 窄屏四张网络指标硬挤一行，速率单位被裁掉。新增审计在旧实现实际报出 `inline metric overflow 97 > 81`；
   改用测宽、均衡分行后通过。
5. 配网页脚固定按钮宽度总和超过窄屏，使连接按钮挤出右侧：改用内容宽度及允许折行。
6. 480×480 的键盘被剩余高度压扁，行与键的边界相互覆盖：键盘、行、键使用主题尺寸下限，正文独立滚动，
   页脚移到卡片根节点保持固定；逐键检查行内边界和滚动后的可见范围。

|---|---|---:|

| 合计 | 15 组 | 1090 |

完整流程包含字体、文本高度、行内数字与单位、边界、卡片重叠、列表顺序、滚动、导航及各覆盖层状态检查。
动效检查仍使用独立的 32ms 响应、180ms 完成预算；虚拟时间与录制帧率不能当作硬件帧率。
实际打开并检查了七英寸五页、窄屏五页、配对输入/指纹/状态卡、诊断和配网键盘截图。
短屏键盘允许滚动查看全部行，按键不再被压缩成互相覆盖的行。

ESP-IDF 构建和四入口静态栈预算检查通过。栈分析是静态下界，不包含函数指针和中断嵌套。

适用边界：这些证据覆盖列出的八种尺寸、测试状态及同一套真实 LVGL 源码；不声称穷举任意尺寸、任意数据，
也没有验证运行中改变显示器分辨率。实际开发板固定为 1024×600。
