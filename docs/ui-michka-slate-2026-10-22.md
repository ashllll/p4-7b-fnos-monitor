## 结构

- **卡片**（`uk_card()`）：头行居中，`[方块帽][标题][方块帽][备注]` 四个直接子对象，标题 `CJK_12` + 字距 1 + 大写式样，头下一条 `line` 细线；卡体使用主题纯色。
- **顶栏**：左列 `主机 · MM/DD` 小字 + `HH:MM` 大号等宽数字（`NUM_20`）。SNTP 未校时前显示 `--:--`，不把 1970 当时间。新鲜度不再常驻，只在过期时出现在状态胶囊前（`保留旧数据 · Ns` / `等待采集端`）。
- **数字字体**：`num_20/32/44` 与 `display_64/96` 由 Chakra Petch 换成 Inter SemiBold；`tools/gen_fonts.sh` 把行高钉回 4px 栅格（24/34/48/61/92），否则 Inter 的较高行距会把卡片撑出 3–6px。
- **密度**：卡片内边距 `12/10`、卡片间距 `8`、主条高 `10`（对齐上游 `padding:10px 12px` 与 9px 轨道）。
- **整行滚动**：池内条目统一行高（取最大者），再由 `uk_viewport_snap()` 摊匀行距，卡底永远停在整行；LVGL 的 `LV_SCROLL_SNAP_*` 试过后放弃——它同样量化程序化滚动，导致"展开全部通道后把最后一行滚进视口"的回归失败。
- **图表**：去掉 Y 轴刻度与"最近 3 分钟 / 现在"角标（上游没有），量程改写进卡头备注 `量程 0 - X`。
