# UniFi 技能 1.1：NAS 全界面迭代

本轮在发布目录的已有 UI 和遥测增强之上迭代，Git 基线为 `6e38282`，保留此前未提交的采集、协议和界面改动。本轮只修改界面、主机验证与文档，不部署 NAS 服务、不烧录或发布。

## 依据与适配边界

采用本机更新后的 `unifi-ui-design` **1.1.0**（核验日期 2026-10-12）。复用技能保存的 L1 桌面与 S1 移动网页观察：Network **10.6.106** / UniFi OS **5.1.33**、深色。没有重新登录控制器，也没有原始个人截图进入仓库。

L1 是 2205×1175 CSS px 桌面界面，包含翻译层；S1 是 15 张 Safari 网页截图，589×1280 是图像像素，CSS 视口、缩放与触控行为未确认。S1 新增的横向导航、任务筛选、分组设置和图表语义用于此次结构迭代；截图中的筛选栏遮挡主表不作为响应式目标。

本项目仍是 LVGL/C、Inter + Noto Sans SC、1024×600 触摸屏。导航尺寸、比较行的展开宽度、详情宽度、字号与动作位置都是项目适配，由主题令牌、配置、字体测量与容器宽度确定，不宣称是 UniFi 官方尺寸。NAS 数据维持真实领域概念，没有添加拓扑、无线信道或虚构历史。

## 界面与操作

| 界面 | 当前结构 |
| --- | --- |
| 外壳 | 独立主机/连接栏；宽屏左侧导航，窄屏顶部横向导航；底部保留采集状态与告警入口 |
| 总览 | 健康结论 → 网络、容量、最热设备摘要 → CPU / 内存历史；摘要与资源标题保留详情入口 |
| 存储 | 全部 / 卷 / 阵列 / 磁盘筛选；总容量摘要；身份、容量、健康与 I/O 按行比较 |
| 网络 | 当前速率、累计量与采集 P95 → 共用量程的上下行趋势 → 接口列表与物理链路占用 |
| 系统 | 全部 / 容器 / 硬件筛选；主机摘要；容器资源、重启与年龄；温度设备摘要；告警入口 |
| 温度 | 当前最热通道与参考范围 → 独立最高温历史 → 设备行；按稳定设备 ID 保存通道展开状态 |
| 告警 | 全部 / 严重 / 警告 / 提示；全局等级计数；分组事件行；区分筛选为空、没有事件和采集失联，明确不含事件历史 |
| 设置与诊断 | 就近 Wi-Fi / 配对入口；连接、采集、运行分组；统一标签和值的对齐、字号与滚动 |
| Wi-Fi | 选择网络 / 连接凭据 / 接入结果三阶段标注；行式扫描清单；键盘、错误恢复和固定页脚 |
| NAS 配对 | 当前状态独立；输入码 / 核对指纹作为主任务，步骤说明并列；窄屏堆叠、页脚可达 |
| 实体详情 | 卷、阵列、磁盘、接口、容器和系统温度摘要行可打开只读面板；宽屏右侧覆盖，窄屏全屏；返回保留原列表位置 |

详情明确显示“打开时快照”：打开时复制身份与完整读数，不保存列表下标或借用字符串。后台刷新、重命名、删除或重新排序不会把面板替换成另一个实体；再次打开读取新快照。遮罩阻挡底层点击和横滑，面板正文独立滚动，返回按钮固定。长文本分配失败显示不可用原因，不能混合上一个实体的残留内容。

分类筛选只是本地显示状态，不改变采集任务；跨页往返保留选择，“全部”恢复完整分类。数量来自当前快照，清单没有固定硬件数量上限。宽行分为身份与指标两列，空间不足改为上下排列；长名称完整换行，设备和通道通过滚动访问。

图表沿用数据层的真实历史、缺口与旧值语义，增加窗口与末端采样标注。最高温曲线表示每次采集的全体通道最大值，不冒充某一传感器的历史。速率、容量、温度、状态和动作继续采用不同语义颜色。

## 2026-10-13：R3 连续曲线与原位换数

用户提供短录屏，并明确选择其中的曲线波动方式与数字跳变作为后续参考。个人 `unifi-ui-design` 1.2.1 已新增脱敏的 R3 动效合同，并记录用户后续“数字跳变还是非常严重，不顺滑”的纠正；原视频仅在本地私有目录备份，未放入技能或发布仓库。应用名称、版本和内部算法没有独立核实，不将观察结论称作官方参数。

参考片段约 6.65 秒；以 30 Hz 抽取 200 帧，吞吐数字检测到 67 次状态变化，约每 100 ms 原位换值，曲线既有峰形连续向左移动。这个观察不要求增加 NAS 请求频率。此次采用的行为如下：

- 六页数字默认以共同显示节拍选择最新真实目标：`FNOS_UI_NUMBER_PRESENT_MS=600`、`FNOS_UI_NUMBER_MS=180`、`FNOS_UI_NUMBER_TRAVEL_PCT=4`，无错峰、模糊或弹跳。固定数值槽与单位，以短时线性字形过渡柔化变化，再留出稳定停顿；不排队播放旧目标。此选择取代中间版本每 200 ms 生硬换值的映射。初始读数、缺失与离线立即呈现；数值与单位作为一组保留或发布，单位变化时原子替换。吞吐主读数根据当前原始历史窗口稳定单位，极小非零值采用有效数字，避免格式化成假零。
- KPI 与总览速率行按可用宽度分配数值槽；百分比按当前字体测量完整整数范围，温度摘要按实际一位小数格式测量最小槽。普通进位不推移单位；更大的温度读数仍可自然扩展，没有引入传感器数值上限。
- 总览 CPU / 内存 / 吞吐、网络吞吐和最高温历史共用原生 LVGL SCATTER 的直线段与显式 X 坐标。仅移动数据时间窗，网格、图框、轴标与周边文字保持原位；保留左侧保护点，避免推进中露出断开的边缘。原始环与显示环独立，当前值、峰值和量程继续使用原始数据。
- 数据层为每个实时样本保存成功接收之间的单调毫秒间隔，并随历史合并、读取携带。当前协议历史只有 epoch 秒，不能提供可信的亚秒源采样时间，因此这是明确的**数据接收时间降级**，不是 NAS 源时间。界面调度不决定滚动时长；提前消费下一个样本时按单调时间推算当前位置，并按剩余距离调整时长，避免帧被跳过后持续落后。短实时合批连续推进；历史回填（包括最终短尾批）、未知间隔、过长间隔、断流恢复、隐藏页和页面切换直接建立最新窗口。
- `FNOS_UI_TREND_SCROLL_MS` 默认 2000 ms，作为可动画间隔上限，设 0 关闭推进；`FNOS_UI_TREND_FPS` 默认 30，作为本地重绘上限，不代表测得的面板帧率。`FNOS_UI_TREND_SMOOTH_SAMPLES` 默认改为 3，保留小波纹与局部峰形；此前默认 9 点的说明属于上一版，不再代表当前默认配置。

新增 X 环在默认七个逻辑序列、180 点时增加 10080 B，数据层间隔环增加 2400 B；没有逐帧创建图表或列表。缺口重置滤波、原始极值保护、长期坐标重基和原生对象删除清理均保留。

验证：连续推进先红后绿；实际 LVGL 大值/全 int32 坐标、原始值与均值分离、恒值、缺口、提前/延后消费、重基和隐藏恢复通过；生产数据层的间隔保持、历史合并与端点重置通过 ASan / UBSan。六页 24 组实际数字/单位行覆盖整数与小数进位、负值、零和缺失。三种趋势页面录制 180 帧，整帧与分块 RGB565 重绘逐像素一致；四种尺寸各 101 张主状态渲染通过。原生滑动/滚动隔离、重复目标、首次入页、动态硬件、快照所有权和分配失败恢复通过。ESP-IDF 构建、任务栈静态下界及四个修改模块的 GCC `-fanalyzer` 通过；静态栈结果仍不覆盖完整间接调用与中断嵌套。

复核补充：历史读取的零行也可能表示锁超时，不能据此结束回填状态。新增“64 点回填 → 锁超时空读 → 2 点尾批”回归，修复前失败、修复后通过；尾批立即建立窗口，不播放旧历史。主机绘制缓冲显式按 `LV_DRAW_BUF_ALIGN` 对齐，避免新增静态测试状态后暴露偶然对齐。
