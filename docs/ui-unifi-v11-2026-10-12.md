# UniFi 技能 1.1：NAS 全界面迭代

本轮在发布目录的已有 UI 和遥测增强之上迭代，Git 基线为 `6e38282`，保留此前未提交的采集、协议和界面改动。本轮只修改界面、主机验证与文档，不部署 NAS 服务、不烧录或发布。

## 依据与适配边界

采用本机更新后的 `unifi-ui-design` **1.1.0**（核验日期 2026-10-12）。复用技能保存的 L1 桌面与 S1 移动网页观察：Network **10.6.106** / UniFi OS **5.1.33**、深色。没有重新登录控制器，也没有原始个人截图进入仓库。

L1 是 2205×1175 CSS px 桌面界面，包含翻译层；S1 是 15 张 Safari 网页截图，589×1280 是图像像素，CSS 视口、缩放与触控行为未确认。S1 新增的横向导航、任务筛选、分组设置和图表语义用于此次结构迭代；截图中的筛选栏遮挡主表不作为响应式目标。

本项目仍是 LVGL/C、Inter + Noto Sans SC、1024×600 触摸屏。导航尺寸、比较行的展开宽度、详情宽度、字号与动作位置都是项目适配，由主题令牌、配置、字体测量与容器宽度确定，不宣称是 UniFi 官方尺寸。NAS 数据维持真实领域概念，没有添加拓扑、无线信道或虚构历史。

## 界面与操作

| 界面 | 当前结构 |
| --- | --- |
| 外壳 | 独立主机/连接栏；宽屏左侧导航，窄屏顶部横向导航；底部保留采集状态与告警入口 |
| 总览 | 健康结论 → 网络、容量、最热设备摘要 → CPU / 内存历史；摘要与资源标题保留详情入口 |
| 存储 | 全部 / 卷 / 阵列 / 磁盘筛选；总容量摘要；身份、容量、健康与 I/O 按行比较 |
| 网络 | 当前速率、累计量与采集 P95 → 共用量程的上下行趋势 → 接口列表与物理链路占用 |
| 系统 | 全部 / 容器 / 硬件筛选；主机摘要；容器资源、重启与年龄；温度设备摘要；告警入口 |
| 温度 | 当前最热通道与参考范围 → 独立最高温历史 → 设备行；按稳定设备 ID 保存通道展开状态 |
| 告警 | 全部 / 严重 / 警告 / 提示；全局等级计数；分组事件行；区分筛选为空、没有事件和采集失联，明确不含事件历史 |
| 设置与诊断 | 就近 Wi-Fi / 配对入口；连接、采集、运行分组；统一标签和值的对齐、字号与滚动 |
| Wi-Fi | 选择网络 / 连接凭据 / 接入结果三阶段标注；行式扫描清单；键盘、错误恢复和固定页脚 |
| NAS 配对 | 当前状态独立；输入码 / 核对指纹作为主任务，步骤说明并列；窄屏堆叠、页脚可达 |
| 实体详情 | 卷、阵列、磁盘、接口、容器和系统温度摘要行可打开只读面板；宽屏右侧覆盖，窄屏全屏；返回保留原列表位置 |

详情明确显示“打开时快照”：打开时复制身份与完整读数，不保存列表下标或借用字符串。后台刷新、重命名、删除或重新排序不会把面板替换成另一个实体；再次打开读取新快照。遮罩阻挡底层点击和横滑，面板正文独立滚动，返回按钮固定。长文本分配失败显示不可用原因，不能混合上一个实体的残留内容。

分类筛选只是本地显示状态，不改变采集任务；跨页往返保留选择，“全部”恢复完整分类。数量来自当前快照，清单没有固定硬件数量上限。宽行分为身份与指标两列，空间不足改为上下排列；长名称完整换行，设备和通道通过滚动访问。

图表沿用数据层的真实历史、缺口与旧值语义，增加窗口与末端采样标注。最高温曲线表示每次采集的全体通道最大值，不冒充某一传感器的历史。速率、容量、温度、状态和动作继续采用不同语义颜色。

## 本轮验证

- `bash tools/gen_fonts.sh`：重新生成字库，没有手改生成物。
- `bash tools/preview/run.sh out-unifi11`：101 张主状态 PNG，以及图表映射、稳定刷新、名称变化、自适应尺寸、快照所有权、空/少量/混合/密集硬件与分配失败恢复。
- 同一 UI 在 480×480、800×480、1024×600、1280×800 完整状态渲染；真实指针测试覆盖导航、分类筛选、恢复全部、跨页保留选择、详情返回、遮罩点击/滑动隔离、后台改名不改变详情身份，以及长名称详情。
- 每帧字形、文本、子对象越界、可点击对象重叠、卡片重叠、格式说明符残留和对比度审计。最低正文对比度 4.54:1；夜间、等待、离线、模块不可用和资源未采集均有样张。
- 原生滑动与滚动隔离 140 帧；重复目标 96 帧；首次系统页 71 帧；800×480 首次配对 7 帧通过。
- `node tools/preview/scroll_gap.js tools/preview/out-unifi11` 与 `--self-test` 检查滚动条证据。详情打开时只审计实际可操作的前景面板，不把被遮挡的背景滚动条当成缺失；普通页面规则保持不变。
- ESP-IDF 5.5.3 / ESP32-P4 rev3 构建通过，无编译警告；7 个任务入口静态栈下界通过。LVGL 入口 4624 / 12288 B，轮询入口 4560 / 6144 B；函数指针调用与中断仍不在静态证明内。

滑动取消回归改为从真实图表边界选取输入点，避免把旧布局的屏幕中心误当作当前空白区。详情新增真实遮罩点按与横滑回归；主机审计只改变遮罩期间的可操作对象范围，所有前景控件仍经过原有布局检查。

构建沿用已核实的 `.em_skill.json` 项目与目标，用 `./idf.sh build` 完成。已安装构建助手存在恢复目标时转入 `set-target` 分支的问题，因此复用工程的验证过的包装脚本；本轮没有重设芯片目标。

以上是主机渲染、交互替身与构建证据，不是实机触摸、帧率、面板色彩或真实采集验收。没有烧录、串口、物理屏幕拍摄、提交或推送。预览位于本地忽略目录 `tools/preview/out-unifi11/`，对比基线保留于 `out-enhanced/`；不将截图和个人固件加入发布源码。
